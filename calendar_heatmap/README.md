# Calendar Heatmap

A calendar heatmap facets daily values into a year-by-week-by-day grid, shading each day cell by its value. Includes auto-capping of outliers (Q3 + 1.5×IQR), a choice of sequential color scheme and scale type, and optional manual overrides for the color domain's min/mid/max.
